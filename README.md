🤖 Autonomous CSV Data Analyst (StatBot Pro)
“Stop cleaning data. Start asking questions.”

StatBot Pro isn't just another LLM wrapper; it is an autonomous data-agent designed to bridge the gap between messy business spreadsheets and actionable insights. By combining the reasoning of LLMs with a strictly isolated Python execution sandbox, StatBot Pro turns your CSVs into a conversation.

🌟 What Makes StatBot Pro Unique?
🛡️ The Sandbox Wall: Unlike standard agents, every line of code generated by StatBot is executed inside a hardened Docker container. If the AI hallucinates malicious code, your host system remains untouched.

🩺 Data Health Guard: Before we analyze, we audit. StatBot automatically profiles your data for missing values, duplicates, and outliers, giving you a "Cleanliness Score" before you even ask your first question.

🧠 Self-Correction Loop: The agent observes its own execution errors. If a query fails due to a KeyError or syntax glitch, the agent autonomously debugs the script and retries, mimicking the workflow of a human analyst.

📊 Executive Briefing: One-click generation of professional PDF reports summarizing your findings, complete with Matplotlib visualizations.

🛠️ The Tech Stack
Built for security and performance.

LLM Engine: LangChain Agentic Framework.

Execution: Docker-based Python REPL.

Visualization: Matplotlib / Seaborn.

Backend: Flask (Production-ready API).

## 🚀 Key Features

* **Autonomous Analyst**: Ask natural language questions; the system writes and executes the necessary code for you.
* **Smart Preprocessing**: Automatically handles common data formatting issues (NA values, inconsistent headers) before analysis.
* **Rapid Visualization**: Quickly derive insights from complex datasets without needing a manual setup.

## 🏗️ Project Structure
- `app.py`: The core Flask web server and routing logic.
- `utils.py`: Preprocessing engine for cleaning and preparing your CSV/Excel files.
- `templates/`: HTML front-end for the dashboard.

🚀 Quick Setup
Clone & Configure:

Bash
git clone https://github.com/shyamnil/autonomous-csv-data-analyst.git
cd autonomous-csv-data-analyst

Bash
pip install -r requirements.txt

python main.py

To test the agent: 
1. Upload a CSV via the UI.

2. Input a query in the prompt box.
  
3. Verify the "Generated Pandas Code" output matches the expected result.

🔒 Security Policy
This project prioritizes Data Sovereignty. By utilizing a sandboxed Docker environment, we ensure that untrusted AI-generated code is limited to volatile memory, preventing unauthorized access to your file system or network.
